# MacroPulse 7.1.2 — visible workout controls and supplement benefits

Fitness now prepares a default 15-minute quick workout without writing user data. The readiness check, 00:00:00 clock, Start workout and adjacent red Stop control are available immediately. Starting begins the existing pause-aware clock; the running control becomes Pause/Resume and red Stop freezes the session for review. Stop is disabled before starting. Choosing another time budget still uses Preview quick workout; routine-day preview remains available. Missing equipment/movement matches show a message without breaking the app.

Each existing supplement now displays its benefit directly beneath its serving option. Evidence, cautions and the existing NIH/MedlinePlus sources remain expandable. No supplement claims or doses were added, and no checkmarks, workout records, photos or persistence schemas were changed.

The experience acceptance suite checks initial timer/control visibility, all ten visible benefits, pause/reload/resume/Stop/Finish and backup/offline behavior.
