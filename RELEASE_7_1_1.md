# MacroPulse 7.1.1 — workout demonstration pictures

All 18 library movements and seven additional template/reference movements have larger, colored start/movement illustrations. Quick Log template and equipment-filtered library pictures are expanded by default. Existing generated routines, live workouts and coaching also use the updated pictures.

Workout logging automatically matches known exercise names. A demonstration selector lets a custom-named exercise use a chosen matching reference; the exercise name and actual sets/load remain unchanged. Saved references appear alongside completed workout entries, persist across reloads and are included in the existing app JSON backup. Unknown names are not assigned an invented exercise. No existing workout records, photo files, database versions or storage keys are rewritten.

The illustrations are simplified original SVG drawings, not photos, video, AI form analysis or a medical assessment. All pictures work offline. Existing written setup and technique cues remain available.

Validation: 70 unit tests and ten browser suites, including a dedicated demonstration suite for visible templates/library, known-name history, automatic matching, custom-reference selection, unchanged original records, backups, mobile width and offline reload. Live deployment verification is recorded in the task output report.
